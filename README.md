# 🌸 Cantikna — Website & Landing Page Brand Guide

Platform gaya hidup, kesehatan, dan kecantikan yang dirancang khusus untuk wanita usia 30-an ke atas dengan nuansa elegan, menginspirasi, dan memberdayakan.

---

## 🔤 Tipografi

* **Headings:** `Playfair Display` (Serif Elegan, Editorial)
* **Body Text:** `Plus Jakarta Sans` (Sans-serif Modern, Ramah, Clean)

---

## 📂 Struktur Section yang Tersedia di `index.html`

1. **Navigation Bar:** Logo monogram C, menu navigasi, dan tombol CTA.
2. **Hero Section:** Headline emosional bertuliskan nama *Cantikna*, sub-headline reflektif, dual CTA, avatar social proof 15k+ wanita, dan frame visual editorial dengan *floating badges*.
3. **Tips Cantik & Menarik:** 3-Column card grid untuk skincare anti-aging (retinol/peptide), fashion capsule wardrobe, dan perawatan kecantikan dari dalam (*inner glow*).
4. **Sharing Kesehatan (Wellness):** Bagian Z-pattern dengan quote redaksi dan 3 pilar kesehatan holistik (hormon/metabolisme, manajemen stres/mindfulness, low-impact exercise).
5. **Rekomendasi Apps (Tech for Women):** Kurasi aplikasi praktis (HydroGlow pelacak hidrasi, GentleMove peregangan 15 menit, CalmHeart jurnal suasana hati).
6. **Newsletter Banner:** Kotak surat hangat bergradasi rose gold dengan form subscription interaktif.
7. **Footer:** Bio singkat, sitemap kategori, sosial media, kontak sahabat, dan copyright.

---

## 🚀 Cara Menjalankan

Buka file `index.html` langsung di browser favorit Anda:
* Klik dua kali `index.html` pada Windows Explorer, atau
* Jalankan lokal server ringan (misalnya dengan VS Code Live Server atau `npx serve .`).
